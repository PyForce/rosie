# About

rosie is a [PyForce](https://github.com/PyForce) project. Its first commit is from August 2015; its web
interface, [WebRosie](https://github.com/PyForce/WebRosie), and its Python client followed in 2017.

rosie 2 (2026) is the same robot software, modernised: Python 3.12+, typed and tested, FastAPI instead of
the original web stack, TOML robot profiles, a rewritten WebRosie, the client folded in, and one Docker image
for everything. The control algorithms are the original ones, checked against the 2018 version along the way;
the go-to-point controller that finishes each movement is new, and so are a few bug fixes.
